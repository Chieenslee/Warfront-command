# Warfront Command

Top-down Python/Pygame war game inspired by the sample project structure, but built as a separate game.

## Features

- Soldier movement with WASD.
- Mouse aiming and shooting.
- Enemy patrol soldiers and tanks.
- Detailed tile map with trenches, roads, walls, water, grass, and a capture point.
- Camera follow, screen shake, muzzle smoke, sparks, explosions, and health bars.

## Run

```powershell
pip install -r requirements.txt
python -m warfront
```

## Controls

- `WASD`: move
- `Mouse`: aim
- `Left click`: fire
- `R`: restart after win/lose
- `Esc`: quit
